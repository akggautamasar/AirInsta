# AirInsta Android 1.1.0

An independent native Android app for viewing and saving public Instagram media.

- A redesigned Studio with full-frame video and carousel previews.
- Saved links and recent links with search and local persistence.
- A Downloads screen with progress, cancellation, fresh-link retries, file opening and sharing.
- Optional Wi-Fi-only downloads and background download notifications.
- Fullscreen video controls with seeking, 10-second skip buttons, playback speed, looping and picture-in-picture on supported devices.
- A photo viewer with pinch zoom, panning and double-tap reset.
- Light and dark appearance, caption copying and sharing links from Instagram.
- An optimized, non-debuggable APK signed with a persistent release key.

Requires Android 10 or later. Internet access is needed to resolve public links; completed downloads can be played from the device.

If the earlier debug/test version is installed, uninstall it before installing this first release because it used a different signing key. Future releases will use the release key.

Only public links supported by the AirInsta extraction service can be resolved. AirInsta is independent of Instagram and Meta.
